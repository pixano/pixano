# Pixano 0.8.0

Pending release. Publication still depends on a compatible `pixano-inference-client`
release becoming available on PyPI and passing the clean-install release checks.

Pixano 0.8 introduces a shared dataset import/export pipeline and a rebuilt
annotation application.

- **Import and export:** strict JSONL v2 and COCO import/export, plus LeRobot
  v2.1/v3 import from local data or Hugging Face. Episodes become annotatable frame sequences
  with state/action vectors. The CLI, REST API, and Python API share analysis,
  validation, and durable jobs with cancellation and resume.
- **Import setup:** configure sources, annotation tools, and typed attributes in
  one screen, review the plan, then follow the accepted import in the jobs tray.
  Required attributes, defaults, and list values work in annotation forms.
- **Explore and annotate:** server-side filtering, stable sorting, configurable
  table/gallery views, and record-level image search using text or similar
  records. Inference runs through the server's `/v1` API.
- **Data safety:** staged create/overwrite imports, guarded add-mode rollback,
  dataset write locks, retry-safe annotation creation, and protection for unsaved
  changes during navigation. Resume verifies original source metadata and settings;
  unverifiable legacy checkpoints require restarting the import.

Compatibility changes: Pixano JSONL imports require v2; the old folder builders and
metadata heuristics are removed, and no legacy JSONL converter is included.
`DatasetBuilder` and the legacy dataset-import API remain deprecated for removal
in 0.9. Inference integrations must use the current `/inference` API.

Known limitations:

- **LeRobot JSONL export/re-import is deferred to 0.9.** Time-series data are
  omitted and annotation schemas can be incomplete. JSONL export is not a
  LeRobot backup format in 0.8.
- The import tray does not restore jobs after a browser refresh; server-side
  jobs continue and remain accessible through the CLI/API. Review plans expire
  after 24 hours, preventing resume of affected jobs; those imports must be restarted.
  Abandoned uploads are cleaned up
  during server startup, rather than periodically.
- Semantic search indexes image records; text-record and per-view embeddings,
  along with 3D annotation features, remain deferred. Inference connections must
  be restored after a backend restart. AV1 playback depends on browser support;
  frame extraction remains available. Import/export jobs require local storage.
