`pixano data import` takes `--embeddings`/`--no-embeddings` and `--embeddings-model` — naming a
model asks for the job —, and says what became of the embeddings jobs of the dataset it imported
into: one per model the dataset already holds too. By default it queues them where a job queue and a
model (`PIXANO_EMBEDDINGS_MODEL`) are configured and the source holds still images.
`pixano data jobs resume` queues what the import was asked for.
