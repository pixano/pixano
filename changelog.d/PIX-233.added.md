`pixano data import` takes `--embeddings`/`--no-embeddings` and `--embeddings-model` — naming a
model asks for the job —, and says whether it queued the embeddings job of the dataset it
imported into. By default it queues it where a job queue and a model (`PIXANO_EMBEDDINGS_MODEL`)
are configured and the source holds still images. `pixano data jobs resume` queues what the
import was asked for.
