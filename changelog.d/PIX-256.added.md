The explorer's API serves a dataset's embeddings model by model. A semantic search names the
embeddings it reads in `model`, a model's name or its space's id, and reads the default ones
otherwise; a text is embedded by that very model. The filters list every model with its health
in `search.spaces`. `GET /datasets/{id}/embedding-spaces` lists them too,
`PUT /datasets/{id}/embedding-spaces/default` makes one of them the default, and
`DELETE /datasets/{id}/embedding-spaces/{space_id}` deletes one model's embeddings and keeps the
others. `POST /datasets/{id}/embeddings/compute` computes another model beside the ones already
there, without `force`. `force` now empties that model's embeddings only, or every model's when
`embeddings.json` cannot be read entirely.
