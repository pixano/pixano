A `detection` job proposes boxes, and the objects they name, for a person to review: it runs the
detection model the inference serves on a dataset's images and writes each box pending review, its
class on its object. A rerun of the same model replaces its own boxes still to review; a box a
person drew or accepted, and a detection that mostly covers one of the same class, are left alone.
`classes` asks for some classes only and replaces only those; `replace_previous`, which the job
form asks to confirm, first deletes every detected box still to review. A dataset imported by URI,
which records no image size, is read for it.
