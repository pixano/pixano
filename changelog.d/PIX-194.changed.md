Saving an edit of a model's annotation accepts it: the API stores it `accepted`, with the model's
provenance and score, whatever the client sent; relabelling a model's classification keeps the
model's score of each label it gave. The one review status an update may ask for is
`accepted` — `pending` and the status a row already has are ignored, any other value is refused —
and a person's annotation takes none. Deleting a model's annotation stays how it is rejected: a
rejected annotation leaves no trace, so a rerun of the model may propose it again, and the dataset
does not record how many proposals were rejected, or edited before being accepted. The legacy app
no longer sends back the review status it read with an edit.
