The default interface reviews what a model proposed on an image. Each entity and annotation a model
proposed shows **Pending review**, with the model and, for a box, its confidence, and **Accept** and
**Reject**. The **Review** switch of the Entities tab puts the record in review: what is still to
review stays in view and the rest fades, with how much is left and **Accept all**, which leaves an
entity with a hidden annotation to review. Decisions are saved with the record's other changes, and
leaving without saving drops them. Once saved, an annotation accepted by an Accept, an edit of it or
an edit of its entity shows **Accepted**. A model's annotation stored with no status, as imported
predictions often are, reads as pending review.
