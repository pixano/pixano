The embeddings job can replace a model's embeddings: `replace_existing_embeddings`, which the new
UI's job form asks to confirm, deletes every vector that model already computed on the dataset
before computing them again; the other models' vectors are kept, and the model's table keeps its
place and stays the default if it was. It is how vectors computed one per record — by the legacy
explorer, or by the embeddings job before it embedded every image — give way to the per-image
ones. A job naming a model the inference does not serve is refused before it starts, before
anything is deleted.
