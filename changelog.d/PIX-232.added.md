An import can queue the embeddings job of the dataset it imported into once it is done, on the
job queue `pixano-worker` consumes: `compute_embeddings` and `embeddings_model` in
`POST /io/imports` — naming a model asks for the job —, and the import job's `follow_ups` say what
became of it. By default it is queued wherever the job can run — a queue where a worker declared
the job, and a model — unless `PIXANO_EMBEDDINGS_AFTER_IMPORT` is false or the import's plan holds
no still image; the model is `PIXANO_EMBEDDINGS_MODEL`, else the first embeddings model the
inference serves. An add import has the job compute the whole dataset again, with the model its
embeddings already use. `GET /io/imports/embeddings` says whether the job can run, and with which
models.
