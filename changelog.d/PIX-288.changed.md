The Docker images no longer run as root. The application's image (`pixano/pixano`) and the
worker's run as a dedicated user, `pixano`, with the user and group numbers 1000. On Linux, the
folder a container mounts must be writable by that user: create it before the first start
(`mkdir my_data`), because Docker creates a missing folder as root, and give it to the user when
an earlier version wrote it as root (`sudo chown -R 1000:1000 my_data`). A named volume that an
earlier version wrote as root needs the same change of owner. Or run the containers as
your own user: `--user "$(id -u):$(id -g)"` with `docker run`, `PIXANO_UID` and `PIXANO_GID` in
`.env` with the compose stack. An image built from the Dockerfiles takes another user with the
build arguments of the same names.
