The explorer sorts and filters records on the groups a clustering made: each run is a column,
named by its algorithm, what it was asked and when, whose values are the groups, the records no
group took in named Noise.
A page of records carries each record's group in each run beside its statistics, in
`computed_values`.
A run of HDBSCAN that found no group says so in its column's name: "…, no group found, …".
