Where a job queue is configured, the import form has a box, "Compute statistics after the import",
below the embeddings' one: it queues the job of the dataset's default statistics once the import is
done. It is checked where the job can run and the server's default
(`PIXANO_STATISTICS_AFTER_IMPORT`) is on, and disabled with the reason where it cannot. A new route,
`GET /io/imports/statistics`, says which.
