A dataset keeps the embeddings of several models side by side, each model in a table of its own
with its own vector index, one of them the default a search uses; a model is its name and its
checkpoint. A dataset whose one model is in the table `embeddings` — every dataset of one model,
until its first model is deleted and another kept — keeps `embeddings.json` as it was, the model's id
and checkpoint added, which an older version of Pixano still reads. Any other dataset describes its
models in a new format, which an older version does not read: computing embeddings there, it would
take the first table for its own and lose the description of every other model. Upgrade the
application and every worker together. An `embeddings.json` this version cannot read entirely is
reported broken and never rewritten: every change to it is refused until it is repaired, or every
model's embeddings are computed again from nothing.
