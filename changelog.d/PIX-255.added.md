A dataset keeps the embeddings of several models side by side, each model in a table of its own
with its own vector index, one of them the default a search uses; a model is its name and its
checkpoint. `embeddings.json` describes them in a new format, which an older version of Pixano does
not read — it sees no embeddings there, and computing some would lose the description of every
model: upgrade the application and every worker together. A dataset embedded by an older version is
read as one model, its vectors kept in their table, and its description is written in the new
format at its first change. An `embeddings.json` this version cannot read entirely is reported
broken and never rewritten: every change to it is refused until it is repaired, or every model's
embeddings are computed again from nothing.
