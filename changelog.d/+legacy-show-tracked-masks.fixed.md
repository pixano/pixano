box tool, with which the object had just been drawn, was still chosen: a drawing tool hides every
shape but the one drawn. It now takes the Pan tool, as a click on an object's row in the timeline
does, and opens the frame after the one the object was tracked from. It is disabled, saying why,
while changes are unsaved, a box or mask tracking session runs, or the Fusion tool is chosen.
