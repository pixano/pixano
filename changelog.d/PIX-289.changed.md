`POST /inference/connect` takes the address of the inference server, its provider type and its
API key in a JSON body (`url`, `provider_type`, `api_key`), and no longer in the query string. A
key in a URL ends up in access logs, in proxies and in browser histories. A request that still
sends `api_key` in the query string is refused with a 422. A script that calls this route must
send the body; the app already does.
