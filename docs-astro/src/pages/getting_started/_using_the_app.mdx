# Using the app

A tour of the three screens you work in: the **Library**, the **Explorer**, and the
**Workspace**.

<Callout type="info" title="What you'll learn">

- How to find a dataset in the Library and flag the ones you care about
- How to filter, sort and browse records in the Explorer
- How the annotation Workspace is laid out, and how to create an entity
- Every keyboard shortcut

</Callout>

## The app header

The header is the same on every screen:

- The **Pixano logo** on the left returns to the Library.
- The **✦ inference chip** shows whether a model server is connected — green dot for connected,
  grey for not. Click it to manage servers and models; see
  [Inference](/pixano/getting_started/inference/).
- The **theme toggle** switches between light and dark.

## Library

The Library lists every dataset in your data directory.

**Toolbar** — search datasets by name, sort by **Name** or **Date**, and **Import** a new
dataset. **Import** opens the import wizard (an empty Library offers it as **Import dataset**);
the [Quickstart](/pixano/getting_started/quickstart/) walks through it once, and every choice it
offers is listed under
[Import from the app](/pixano/getting_started/importing_data/#import-from-the-app). A running
import shows in a tray at the bottom right, and its card appears when it finishes. The record
total for the whole library sits on the right.

**Tabs** — datasets can be flagged, and the tabs let you jump between those groups without
scrolling: **All**, **Todo**, **New** and **Favorite**, each with a count. Flag a dataset by
hovering its card and clicking one of the three coloured flags in the corner — blue for Todo,
green for New, yellow for Favorite. Active flags stay visible; the rest appear on hover.

Each card shows the dataset's preview, its type, the number of records, and a bar breaking the
dataset down by split and annotation status. Click a card to open it.

## Explorer

The Explorer is where you browse and triage the records of one dataset.

### Finding records

- **Filters** — click **Filter** to add a typed condition (a column, an operator, a value).
  Each condition becomes a chip you can edit or remove. Conditions are validated against the
  dataset's columns, so a malformed query is rejected rather than half-applied.
- **Split and Status facets** — one-click multi-select for the two fields you filter on most,
  with counts.
- **Search** — the search bar is semantic; see
  [Semantic Search](/pixano/getting_started/semantic_search/).
- **Sort** — pick a column and a direction. Sorting happens server-side, so it is correct
  across pages, not just within the page you are looking at.

Use **Clear all** to drop every filter at once.

### Views

Toggle between **gallery** and **table**:

- **Gallery** shows one card per record, built from whatever previews it carries — a single
  image, a multi-view mosaic, a video frame, or a text excerpt.
- **Table** shows one row per record. The **column settings** popover lets you show, hide and
  reorder columns.

Both views let you choose how many records to show per page. Clicking a record opens it in the
Workspace.

When a model's annotations wait for review on an image dataset, **Review** shows how many
records hold some, and opens the first of them in review — see
[Reviewing what a model proposed](#reviewing-what-a-model-proposed).

## Workspace

The Workspace is where annotation happens.

### Header

The header reads `← <dataset> · ‹ n / m ›`:

- The **back arrow** and the **dataset name** both return to the Explorer, landing on the page
  that contains this record under your active filters.
- The **chevrons** step to the previous and next record *within the current filter and sort* —
  not the whole dataset. Hover the counter to see the record's id.
- On the right, **Save** shows how many changes are pending; when there is nothing to save it
  reads **✓ Saved**.

The annotation tools sit in the middle of the header.

<Callout type="note" title="Nothing is lost by accident">
Navigating away with unsaved changes prompts you to save, discard, or stay.
</Callout>

### Tools

| Tool | Shortcut | Notes |
|------|----------|-------|
| Pan | `Esc` | Move and zoom the image |
| Bounding box | `R` | Click and drag |
| Polygon | `P` | Keep the raw polygon, or convert it to a mask |
| Polyline | `L` | `N` finishes a sub-path |
| Brush | `B` | `X` toggles pencil/eraser; `Q`/`E` resize |
| Smart segmentation | `W` | Needs a connected model — see [Inference](/pixano/getting_started/inference/) |

Two more controls sit at the end of the toolbar: **Display settings** (image smoothing,
histogram equalization, brightness, contrast, RGB channels, and the 16-bit range) — these
change how the image is displayed, never the data — and a **keyboard shortcuts** reference.

### The side panel

The panel on the right has two tabs:

- **Entities** — every entity in the record. Expand a card for its **Attributes** (the entity's
  fields) and its **Annotations** (the boxes, masks and text spans attached to it). A search box
  filters entities by any attribute.
- **Record** — everything about the record itself: its **Status**, its **Attributes**, and
  per-**View** metadata.

### Creating an entity

Draw a shape and press `Enter`. The creation form opens:

1. **Parent entity** — keep **Create new entity**, or attach the annotation to an existing one.
   The picker shows a thumbnail, name and composition for each candidate, and marks whether
   linking would **Move** the annotation, **Merge** it, or is blocked by a conflict.
2. **Attributes** — fill in the entity's fields. Value pickers suggest what you have used
   before, and offer an explicit `Create "…"` row for a genuinely new value.
3. **Confirm** — the annotation is staged. Nothing is written until you press **Save** in the
   header. `Esc` cancels.

### Reviewing what a model proposed

A model's annotations — predictions imported with the dataset, for instance — are *pending
review* until a person decides on them. On an image record, the **Entities** tab shows, on each entity and on each annotation a model proposed,
**Pending review** with the model and, for a box, its confidence:

- **Accept** keeps it as the model proposed it.
- **Reject** deletes it, and the entity too once nothing else is left on it.

On an entity, both act on what it shows: an annotation hidden, with its eye or by a filter, stays
to review. Saving an edit of a model's annotation, or of its entity, accepts it too.

The **Review** switch at the top of the **Entities** tab puts the record in review: what is still
to review stays in view on the image and the rest fades. It says how much is left on the record,
and **Accept all** accepts the entities shown — an entity with a hidden annotation, with its eye or
the confidence filter, stays to review whole, its mask with its box.

In review, the keyboard works with the Pan tool, one annotation at a time. A record opened in
review puts its first annotation to review under review: it is shown alone on the image, and
outlined in its entity's card. `Enter` accepts it and `Delete` (`Backspace` on a Mac keyboard)
rejects it, then the next one comes under review — the entity's next annotation, then the next
entity's; like Accept all, the keys leave an entity with a hidden annotation to review whole.
Accepting or rejecting it with the mouse moves on the same way. Clicking an entity's card puts its
first annotation to review under review. A click on a box selects it without editing it — `E` or
the pencil edits it —, and a click beside the shapes keeps the review: to see the whole record,
turn the switch off. Once nothing is left, `Enter` offers to save and go to the next record: press
it again to do so, or any other key to stay. `Enter` still presses a button you reached with `Tab`.

Decisions are staged like any change: **Save** writes them, and leaving the record without
saving drops them. In review, the header offers **Save & next**, which saves and opens the next
record to review, and says how many records are left. The next record follows the order of the
records' ids over the whole dataset, whatever the Explorer's filters and sort; on the last record
to review, it saves and stays. Video and 3D records are not reviewed.

## Keyboard shortcuts

| Category | Shortcut | Action |
|----------|----------|--------|
| General | `Esc` | Switch to the Pan tool |
| | `Delete` / `Backspace` | Delete the selected point |
| | `Ctrl+S` / `⌘+S` | Save all annotations |
| | `Alt` (hold) | Peek at existing annotations |
| Navigation | `Shift+→` | Next record |
| | `Shift+←` | Previous record |
| Review mode | `Enter` | Accept the annotation under review, then review the next |
| | `Delete` / `Backspace` | Reject the annotation under review, then review the next |
| | `Enter`, `Enter` | Nothing left on the record: save and go to the next one |
| Bounding box | `R` | Activate the tool |
| | `Enter` | Validate the box |
| Polygon / polyline | `P` / `L` | Activate polygon / polyline |
| | `N` | Finish a sub-path |
| | `Enter` / `Esc` | Validate / cancel the path |
| Brush | `B` | Activate the brush |
| | `X` | Toggle draw / erase |
| | `Q` `[` / `E` `]` | Smaller / larger brush |
| | `S` / `Enter` | Save the mask |
| Smart segmentation | `W` | Activate |
| | `X` | Toggle the +/− point prompt |
| | `R` | Box prompt |
| | `Enter` | Validate the mask |
| Video | `Space` | Play / pause |
| | `→` / `D` | Next frame |
| | `←` / `A` | Previous frame |

## Video records

Video records add a timeline below the image. Select an entity in the **Entities** tab to
reveal its track along the timeline; pin up to two to compare them. Coloured segments are
tracklets — continuous stretches where the entity is visible — and dots are keyframes. Right
click a tracklet to add a point, split it, glue it to a neighbour, relink it, or delete it.
