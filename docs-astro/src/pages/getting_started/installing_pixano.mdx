# Installation

To install Pixano with pip you need a working Python installation. It currently requires
**Python 3.10 to 3.13**. We encourage installing Pixano in a virtual environment, or using the
Docker distribution. Pixano is supported on Linux and macOS, and on Windows with limited support.

## Install with pip

Create a virtual environment and activate it:

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

On Windows, activate with `.venv\Scripts\activate` instead.

Install Pixano:

```bash
pip install pixano
```

Create a data directory — the folder where Pixano keeps your datasets:

```bash
pixano init ./my_data
```

Start the server:

```bash
pixano server run ./my_data
```

Open **http://127.0.0.1:7492** in your browser. You are on Pixano's home page, the Library —
empty for now. Press `Ctrl-C` in the terminal to stop the server.

Continue to the [Quickstart](/pixano/getting_started/quickstart/) to import your first dataset.

## Run with Docker

Pull the image and start a container:

```bash
docker pull pixano/pixano:stable
```

```bash
docker run -d --name pixano -e DATA_DIR=/library -p 7492:7492 -v "$(pwd)/my_data:/library" pixano/pixano:stable
```

`my_data` is a folder on your machine where Pixano keeps your datasets; it is created on first
start. Open **http://localhost:7492** in your browser: the Library.

Stop the container with `docker stop pixano` and start it again with `docker start pixano`.
