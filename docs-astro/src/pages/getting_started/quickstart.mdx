# Quickstart

Import a local image directory, configure its annotation schema, and inspect the dataset in
the Explorer.

## Prerequisites

- Pixano running (see [Installation](/pixano/getting_started/installing_pixano/)).
- A flat directory containing only JPEG or PNG files (no subdirectories).

<Callout type="note">

The example folder, `my_images_dataset`, contains three images. Record counts depend on the
selected files.

</Callout>

## Import with the wizard

1. Open Pixano in a browser. In the empty Library, click **Import dataset** to open the import
   wizard.

<Figure src="getting_started/quickstart/01-library-empty.webp"
  alt="The empty Library: 'Your library is empty' with the Import dataset button."
  caption="Empty Library." />

2. In **Setup**, use the **Source** pane on the left to select **Raw media**.
3. In **Annotation setup** on the right, select **Image annotation**. **Bounding boxes** and
   **Masks** are enabled by default; **Polygons & lines** is optional. Add **Object attributes**
   such as `category` (String) if required by the annotation schema.
4. In **Source**, click **Choose a folder** and select `my_images_dataset`. After upload,
   **Detected layout** reports 3 records, each with one `image` view.
5. Leave **Dataset name** empty to use the folder name. Keep **Overwrite existing dataset**
   unchecked for a new dataset, then click **Review import**.

<Figure src="getting_started/quickstart/02-wizard-source-detected-layout.webp"
  alt="Setup with Source on the left and Annotation setup on the right: my_images_dataset is uploaded, 3 records are detected, and bounding boxes and masks are selected."
  caption="Setup: source configuration and annotation schema." />

6. In **Review**, check the record count, **Media views**, **Annotation setup**, and **Sample
   records**. Analysis does not create the dataset. Use **Edit setup** to make changes, or click
   **Start import**.

<Figure src="getting_started/quickstart/03-wizard-review-plan.webp"
  alt="Review import showing 3 records, the image view, bounding box and mask tools, and sample records."
  caption="Review the import plan before starting the job." />

7. The wizard closes and the import runs in the background. The job tray shows progress and a
   **Cancel** control. On completion, the Library updates automatically with the new dataset.

<Figure src="getting_started/quickstart/04-library-dataset-card.webp"
  alt="The Library with the new my_images_dataset card and an Imported status in the background job tray."
  caption="The Library updates automatically when the background import completes." />

<Callout type="note">

The same **Setup → Review** flow supports video, Visual Q&A, and image–text annotation tasks,
plus existing Pixano, MS COCO, and LeRobot datasets. Select the data format in **Source** and
configure applicable tools and attributes in **Annotation setup**. In a raw media directory,
`train/`, `val/`, and `test/` subdirectories become splits.

</Callout>

## Inspect the dataset

Click the dataset card. The **Explorer** lists the records in a gallery, one per image. Click a
record to open it in the annotation **Workspace**.

<Figure src="getting_started/quickstart/05-explorer-records.webp"
  alt="The Explorer showing the three records of my_images_dataset in the gallery."
  caption="Explorer, gallery view." />

Each image is stored as a **record** with a single **view**. Annotated objects are **entities**;
each bounding box, mask, or polygon attached to an entity is an **annotation**. Review summarizes
the views, annotation tools, and custom attributes. See
[Key Concepts](/pixano/getting_started/key_concepts/) for the data model.

### Define the schema with dataset.yaml

Without a configuration file, the CLI creates the `bbox` and `keypoint` annotation tables; the
wizard's image preset creates `bbox` and `mask`. To control the schema, add a
`dataset.yaml` at the root of the source directory.

Create `my_images_dataset/dataset.yaml`:

```yaml
pixano: 2
format: pixano_jsonl
dataset:
  name: my_images_dataset_detection
  workspace: image
schema:
  entity:
    attrs:
      category: str
  annotations: [bbox, mask]
```

- `dataset`: the name and the workspace (set by the cards in the wizard).
- `schema`: adds a `category` string attribute to every entity and restricts the annotation
  tables to `bbox` and `mask`.

Pixano detects the file automatically. No option is needed; the name comes from the file:

```bash
pixano data import ./my_data ./my_images_dataset
```

The plan now reflects the file:

```text
Schema (workspace: image):
- View 'image': Image
- Entity attrs: category: str
- Annotations: bbox, mask
```

See [Key Concepts](/pixano/getting_started/key_concepts/) for workspaces, entities, and
