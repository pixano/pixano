# Quickstart

This guide walks through importing a local directory of images into Pixano and inspecting the
dataset in the web explorer.

## Prerequisites

- Pixano running (see [Installation](/pixano/getting_started/installing_pixano/)).
- A flat directory containing only JPEG or PNG files (no subdirectories).

<Callout type="note">

Examples use a sample folder named `my_images_dataset` containing three images. Metric counts in
the interface will reflect your local files.

</Callout>

## Import with the wizard

1. Open Pixano in a browser. In the empty Library, click **Import dataset** to open the import
   wizard.

<Figure src="getting_started/quickstart/01-library-empty.webp"
  alt="The empty Library: 'Your library is empty' with the Import dataset button."
  caption="Empty Library." />

2. **Type**: select **Raw media** (unlabeled images, videos, or text files to annotate in
   Pixano).
3. **Task**: select **Image annotation**.
4. **Source**: click **Choose a folder on your computer…** and select `my_images_dataset`. After
   the upload, **Detected layout** reports 3 records, each with one `image` view.
5. Keep the defaults and click **Analyze**. The dataset takes the folder name. The pre-selected
   **Annotations** chips (`bbox`, `mask`, `keypoint`, `classification`) define the annotation
   tables to create.

<Figure src="getting_started/quickstart/02-wizard-source-detected-layout.webp" width={768}
  alt="The Source step after uploading the my_images_dataset folder: 3 files uploaded and the Detected layout panel showing 3 records."
  caption="Source step. The folder is the only required input." />

6. **Review**: nothing is written at this stage. Check the plan (record count, **Schema**,
   **Sample records**), then click **Start import**.

<Figure src="getting_started/quickstart/03-wizard-review-plan.webp" width={768}
  alt="Review the plan: 3 records, the schema Pixano will create, and sample records."
  caption="Review step. The import plan." />

7. **Import**: when the wizard reports **Dataset imported**, click **Done**. The dataset appears
   in the Library.

<Figure src="getting_started/quickstart/04-library-dataset-card.webp"
  alt="The Library with the new my_images_dataset card."
  caption="Library after the import. Subsequent imports start from the Import button." />

<Callout type="note">

The wizard follows the same steps for other inputs: video, Visual Q&A, and image–text tasks
(**Task** cards), and existing datasets in Pixano export, MS COCO, or LeRobot format (**Type**
cards). In a raw media directory, `train/`, `val/`, and `test/` subdirectories become splits.

</Callout>

## Inspect the dataset

Click the dataset card. The **Explorer** lists the records in a gallery, one per image. Click a
record to open it in the annotation **Workspace**.

<Figure src="getting_started/quickstart/05-explorer-records.webp"
  alt="The Explorer showing the three records of my_images_dataset in the gallery."
  caption="Explorer, gallery view." />

Each image is stored as a **record** with a single **view**. Annotated objects are **entities**;
each bounding box, mask, or keypoint set attached to an entity is an **annotation**. These are
the four schema sections listed in the Review step. See
[Key Concepts](/pixano/getting_started/key_concepts/) for the data model.

### Define the schema with dataset.yaml

Without a configuration file, the CLI creates the `bbox` and `keypoint` annotation tables; the
wizard's image preset also creates `mask` and `classification`. To control the schema, add a
`dataset.yaml` at the root of the source directory.

Create `my_images_dataset/dataset.yaml`:

```yaml
pixano: 2
format: pixano_jsonl
dataset:
  name: my_images_dataset_detection
  workspace: image
schema:
  entity:
    attrs:
      category: str
  annotations: [bbox, mask]
```

- `dataset`: the name and the workspace (set by the cards in the wizard).
- `schema`: adds a `category` string attribute to every entity and restricts the annotation
  tables to `bbox` and `mask`.

Pixano detects the file automatically. No option is needed; the name comes from the file:

```bash
pixano data import ./my_data ./my_images_dataset
```

The plan now reflects the file:

```text
Schema (workspace: image):
- View 'image': Image
- Entity attrs: category: str
- Annotations: bbox, mask
```

See [Key Concepts](/pixano/getting_started/key_concepts/) for workspaces, entities, and
